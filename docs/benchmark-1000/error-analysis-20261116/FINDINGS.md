# 接入 OCR 版本的 927 张未完全一致表格：分析结论

分析日期：2026-11-16。对象为原 `current` 流程：TATR + PP-OCRv6 small，1000 张固定测试图，AccCon 为 7.30%（73 张）。本次未修改原始预测、OCR、模型、后处理算法或评价分数。

**927 张全部完成程序分类，并对 14 张跨类别案例查看了原始图片。没有声称逐字人工检查了全部 927 张。**文字差异以本实验采用的官方词信息为参考；该参考不保证与可见图像逐字无误。

## 2. 结构问题与内容问题的分离

1000 张中有 **815 张结构拓扑完全匹配**。其中 73 张内容完全一致，另 **742 张结构匹配但内容不完全一致**。这说明结构模型并非全部问题的来源，但不能据此把 742 张都叫作 OCR 识错。

185 张结构不一致中：

- **73 张**行数或列数不同：66 张行数不同、7 张列数不同。
- **112 张**行列数量相同，但合并/单元格划分不同。

结构不一致表格仍可能同时存在文字错误；本次不把错位后的相同行列下标强行当作正确对应关系。完整 JSON 保存参考/预测行列数、单元格数、跨格数量、跨度差异及重叠写入信息。

185 张结构不一致中，155 张为复杂表、30 张为简单表。简单/复杂按参考是否存在跨行或跨列单元格定义，不等同于图片大小或视觉难度。

## 3. 在 742 张结构一致的内容错误表中，观察到了什么

以下是可重叠标签，**不可相加当作表格总数，也不等于已确认的视觉根因数量**。

| 观察 | 表格数 |
|---|---:|
| 至少存在一处其他非空文字内容差异 | 634 |
| 标点/符号字符序列不同 | 571 |
| 字母字符序列不同 | 509 |
| 至少一处空格或换行差异 | 498 |
| 数字字符序列不同 | 376 |
| 至少一个参考非空、预测为空的单元格 | 128 |
| 缺失的整格内容中包含纯标点/横线 | 79 |
| OCR 框几何上明显覆盖多个预测单元格 | 76 |

“数字字符序列不同”不包含所有数值错误。例如 `2.2 → 22` 数字序列仍为 `22`，但小数点丢失已经改变数值含义。不能将 376 张当作全部数字错误总数。

这 742 张的原始单元格划分可以一一对应、没有重叠写入。按去重后的单元格计：59 张只有一个单元格存在文本差异，151 张最多三个单元格有差异，差异单元格数量的中位数为 8。严格整表指标会把“一处小差异”和“许多差异”都计为整表不完全一致。

仅空白差异的 70 张值得先处理，但不是全部问题。对 815 张结构匹配表做**诊断字符串比较**时：合并连续空白后相等的有 103 张，移除全部空白后相等的有 143 张。这些数值包含原来正确的 73 张，**不是重新评分的准确率，更不能把官方评估改成忽略空白后宣称提升**。

## 5. 对匹配问题能下什么结论

自动检索发现 76 张结构匹配的错误表存在跨界 OCR 框；4 张存在“唯一完整参考文本出现在别格”的线索；5 张存在“原始 OCR 已识出完整参考文本却被放到不同跨度”的线索，其中 1 张还有较强的参考位置重叠证据。

**这些都是保守检索得到的候选，不是完整错配率，也不能相加。**多列文字合成一个长框时，整格文本未必能在别格完整匹配，因此会漏掉 `Gene name UCP1` 这类实际错配。该例是在原图与 OCR token 追踪中另行确认的。

128 张含整格缺失的表中，31 张至少有一处缺失格附近存在 OCR 框，108 张至少有一处缺失格没有达到诊断重叠条件的 OCR 框；同一表可能两种都有。附近有框不保证框内是正确文字；没有框也可能来自框偏移、参考范围或检测遗漏，不能自动断言全部是 OCR 漏检。

## 6. 后续优先级

1. **先修可解释的文字组织问题**：区分输出换行、OCR 内部空格缺失、上标/脚注与符号码位；不能简单删除所有空格或标点。
2. **针对实际跨列、错行案例改进词级分配和边界鲁棒性**：不要只根据 OCR 置信度判断；高置信度长框仍会跨格。
3. **针对可疑数字、小数点、科学符号及确有前景的空格设计局部重识别**，保留原结果与候选，不对所有真空格强行补字。
4. **结构层面另行处理行层级、合并关系和空白格保护**。单纯调整最终 bbox 不会修正上述文字内容差异，也不会自动提升 AccCon。
5. **参考/图像不一致的案例单独报告**。保持原评分，必要时增加人工核验说明；不能为了提高分数修改参考或事后更换测试样本。

这些测试图已经用于错误分析，后续规则与阈值应在独立验证数据上确定，并补充未参与设计的最终测试图。当前千图保留为回归对比，不将这里的诊断归一化数字当成新的实验成绩。

## 7. 核验与复现

- 原 1000 张均覆盖，73 张完全一致、927 张错误 ID 唯一；七个主分类合计 927。
- 重建参考的行、列、单元格和跨格数量均与原评价记录一致；从原 TATR/OCR 缓存重建的融合单元格逐项等于原导出。
- 6003 个原始输入、评分与导出文件的前后 SHA-256 一致；官方 GriTS/AccCon 没有重新计算或改写。
- 原先 798 张诊断子集的 48,583 个网格位置、9,606 个差异位置、3,095 个纯空白差异位置等均与既有诊断一致。本次将范围扩展到了全部 927 张错误表。
- 之前的 798 张子集要求官方基线也预测完全正确；本次直接由 XML 和官方词信息重建评价参考，不再依赖官方基线预测是否正确，因此覆盖全部 1000 张和其中全部 927 张失败。
- HTML 做离线结构核验；自动浏览器预览因本地 `file://` 安全策略被拒绝，未声称完成浏览器交互验证。可在本地自行打开 `index.html` 按 ID 和类别筛选。
- 最终本地 55 项单元测试通过；独立审查核对分类、计数、原分数和 14 张案例，未发现重要问题。诊断命令拒绝将报告或缓存写入原实验目录。
